# Summary
- Local multiplayer game similar to Jackbox games
- No rooms, everyone in the same game
- One computer opens a website and keeps it open on a big screen.
- Big screen website is the homepage with a QR code that anyone can scan on their own device to be forwarded to the url of the game.
- Once player gets to the url they are asked to input a nickname and pick a character avatar
- Then they get to submit a symptom as a patient
- If they would rather skip adding a symptom and instead prescribe a treatment they can skip the patient part and go directly to doctor mode
- There needs to be a handful of premade symptoms so those players that skip the symptom part early on would still get a symptom they can prescribe treatment for.

# Patient
- In patient mode player gets a random symptom template that is missing some words and they can fill those in.
- For example a symptom template could be: "Whenever I _______, I get this urge to _______."
- There could be some premade options for each slot to chose from, but player would be able to input whatever they want.

# Doctor
- Once player has submitted a symptom or if they decide to skip the Patient phase they are taken to the Doctor phase
- In doctor phase player gets a symptom that is filled in and has to write a treatment/prescription

# Voting
- Once player has completed the Doctor phase they are offered one symptom with 2 different perscriptions and they can thumbs up one or both
